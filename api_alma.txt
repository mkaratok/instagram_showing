📘 Instagram Graph API: Altın Kurulum Kılavuzu

Bu işlemlerin hatasız çalışması için "Sıfır Hata" kuralı: Facebook Sayfası ve Instagram İşletme Hesabı birbirine kesinlikle bağlı olmalıdır.
1. Adım: Graph API Explorer Hazırlığı

Adres: developers.facebook.com/tools/explorer

    Meta App: Sağ tarafta doğru uygulamanın seçili olduğundan emin ol.

    User or Page: Daima "User Token" seçili başla.

    Permissions (İzinler): İhtiyacın olan izinleri tek tek arayıp ekle.

        Standart Paket (Zorunlu): instagram_basic, pages_show_list

        Yorum/DM Paketi (v2 İçin): instagram_manage_comments, instagram_manage_messages

        İstatistik Paketi: instagram_manage_insights

        Webhook Paketi: pages_manage_metadata

2. Adım: Facebook Login Penceresi (⚠️ EN KRİTİK ADIM)

Mavi "Generate Access Token" butonuna bastığında açılan pencere kader anıdır.

    Ekran 1 (Instagram Hesapları):

        Asla tek bir hesap seçme.

        Mutlaka "Tümünü Seç" (Select All) kutucuğunu işaretle.

    Ekran 2 (Sayfalar):

        Burada da "Tümünü Seç" (Select All) yapmalısın.

        Neden? Eğer sadece tek sayfayı seçersen, yarın başka bir müşteri eklediğinde Token bozulur, her şeyi baştan yapman gerekir. Hepsini seç, kafan rahat olsun.

3. Adım: Doğru ID'yi Bulma (Formül)

Token'ı aldın. Şimdi ID avına çıkıyoruz. Explorer adres çubuğuna şunu yaz:

Sorgu: me/accounts?fields=name,instagram_business_account

Doğru Sonuç Analizi: Gelen JSON verisinde şuna bakacaksın:
JSON

{
  "name": "Sayfa Adı (Örn: Bumudurbu)",
  "instagram_business_account": {
     "id": "1784XXXXXXXXXXX"  <-- İŞTE BU! (Bizim Hazine)
  },
  "id": "1056XXXXX" <-- BU YANLIŞ! (Bu Facebook Sayfa ID'sidir, sakın alma)
}

    Kural: Instagram ID'leri her zaman 1784... ile başlar. Başka bir şeyle başlıyorsa yanlıştır.

4. Adım: Token Ömrünü Uzatma (Long-Lived Token)

Explorer'dan aldığın token sadece 1 saat yaşar. Bunu 60 güne çıkarmadan projeye ekleme.

    Token kutusunun yanındaki mavi "i" (Bilgi) ikonuna tıkla.

    Açılan küçük pencerede "Open in Access Token Tool" butonuna bas.

    Yeni açılan sayfada altta mavi bir buton göreceksin: "Extend Access Token" (Erişim Jetonunu Uzat).

    Ona basınca sana yeni ve upuzun bir şifre verecek.

    İşte projendeki .env dosyasına koyacağın şifre budur.

🆘 Acil Durum Çantası (Sorun Çıkarsa)

Senaryo A: data: [] (Boş Liste) Geliyor

    Sebep: Facebook Sayfan ile Instagram hesabın arasındaki bağ kopmuş veya onaylanmamış.

    Çözüm: Facebook Sayfa Ayarları -> Bağlı Hesaplar -> Instagram'a git. Bağlantıyı kesip tekrar bağla ("Review Connection" uyarısı varsa onayla).

Senaryo B: Token Hatası (Error 190 / 466)

    Sebep: İzinleri değiştirdin ama token eski kaldı.

    Çözüm: Explorer sayfasını F5 ile yenile. Token kutusunu temizle ve baştan "Generate Token" de.

Senaryo C: ID'yi Bulamıyorum

    Çözüm (Manuel): Facebook Sayfanın "Hakkında/Şeffaflık" kısmından Facebook Sayfa ID'sini bul (Örn: 105...). Explorer'a FACEBOOK_SAYFA_ID?fields=instagram_business_account yaz. Sana 1784'lü numarayı verecektir.

Bu kılavuzla artık sırtın yere gelmez! Yeni özellikler eklerken (v2, v3) sadece izinleri (Permissions) güncelleyip bu adımları tekrar etmen yeterli.
